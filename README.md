# Student Manager

Простое консольное приложение для управления списком студентов, написанное на **Kotlin**.

## 📋 Описание

Приложение позволяет:
- ✅ Просматривать список всех студентов
- ✅ Добавлять новых студентов
- ✅ Искать студента по имени
- ✅ Показывать только совершеннолетних студентов (от 18 лет)
- ✅ Удалять студентов из списка

## 🛠️ Структура проекта

### Классы

**`Student`** — data class для хранения информации о студенте:
- `name` — имя студента
- `age` — возраст
- `group` — номер группы (например, "ИТ-101")
- `course` — номер курса

**`StudentManager`** — управляет списком студентов:
- `showStudents()` — вывести всех студентов
- `addStudent(student)` — добавить студента
- `findStudent(name)` — найти студента по имени
- `showAdults()` — показать совершеннолетних
- `removeStudent(name)` — удалить студента по имени

## 🎮 Использование

```bash
$ kotlinc prjct -include-runtime -d prjct.jar && java -jar prjct.jar
```

После запуска вы увидите меню:

```
=== STUDENT MANAGER ===
1. Показать студентов
2. Добавить студента
3. Найти студента
4. Показать совершеннолетних
5. Удалить студента
0. Выход
```

Введите номер команды для выполнения действия.
